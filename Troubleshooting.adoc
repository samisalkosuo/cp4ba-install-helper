= Troubleshooting

== 24.0.0 - trusted certificates

If connecting to external services from (for example) Workflow, add certificate secrets to CR. 

For example, if secret is named `cpd-route-tls-secret` add following to CR:

```
spec:
  shared_configuration:
    trusted_certificate_list:
    - cpd-route-tls-secret
```

== 24.0.0 - graphiQL is not deployed

By default, graphiqQL is not available. Add following to CR:

```
spec:
  ecm_configuration:
    graphql:
      graphql_production_setting:
        enable_graph_iql: true
```

Verify that graphql is available: https://cp4ba.example.com/content-services-graphql/.

== 24.0.0 - viewone-deploy is not deployed

viewone-deploy shows error:

```
JVMJ9GC028E Option too large: '-Xmx (as set by -XX:MaxRAMPercentage)'
JVMJ9VM015W Initialization error for library j9gc29(2): Failed to initialize
Error: Could not create the Java Virtual Machine.
Error: A fatal exception has occurred. Program will exit.
```

Fix by adding to CR:

```
spec:
  ecm_configuration:
    document_processing:
      viewone:
        auto_scaling:
          enabled: false
        viewone_production_setting:
          #set value 50 or lower if not working
          jvm_max_heap_percentage: 50
```
